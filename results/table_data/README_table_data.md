# Table data files

This folder contains the CSV files used by the Python table generator.

The table-data layer is generated by Octave using:

`experiments/build_table_data_csvs.m`

Tables 1 to 3 are conceptual and methodological tables generated directly by this script.
Tables 4 to 9 are derived from the locked figure-data CSV files, so tables and figures use the same numerical source.

Files:

- table_01_constructs.csv
- table_02_baseline_parameters.csv
- table_03_experimental_design.csv
- table_04_baseline_architecture.csv
- table_05_mechanism_decomposition.csv
- table_06_translation_capability.csv
- table_07_boundary_spanner_load.csv
- table_08_selection_rule_robustness.csv
- table_09_readiness_threshold_robustness.csv
