# Boundary-Spanning Relational Readiness

This repository contains the computational procedures used to study how the
allocation of scarce cross-boundary interaction capacity affects the time and
tail risk associated with relational coordination readiness in modular R&D
collaboration networks.

## Status

This is a private development repository associated with an academic
manuscript currently under preparation. The model, documentation, parameters,
and reproduction procedures remain under development.

## Repository structure

- `src/octave/`: core Octave simulation functions
- `src/python/`: statistical analysis and figure-generation code
- `scripts/`: experiment execution scripts
- `config/`: baseline and robustness parameters
- `docs/`: model specification and computational protocol
- `seeds/`: random seeds
- `results/reference_results/`: small reference outputs
- `figures/`: manuscript figures

## Software

The simulations are implemented primarily in GNU Octave. Python may be used
for statistical analysis and figure generation.
