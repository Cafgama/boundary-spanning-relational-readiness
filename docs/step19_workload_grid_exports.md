# Step 19 — Workload-grid diagnostics and export

## Purpose

Step 19 reads the processed workload-grid production output and exports clean CSVs plus a manuscript handover document.

This step does not run simulations. It only analyzes an existing processed workload-grid `.mat` file.

## New script

```text
experiments/rerun_v2/analyze_workload_grid_results.m
```

Usage:

```octave
analyze_workload_grid_results
```

or:

```octave
analyze_workload_grid_results('path/to/workload_grid_processed_YYYYMMDD_HHMMSS.mat')
```

If no file is provided, the script uses the latest:

```text
results/processed/rerun_v2/workload_grid/workload_grid_processed_*.mat
```

## Inputs

The expected production file is generated by:

```text
experiments/rerun_v2/run_workload_grid_production.m
```

The production design is:

- architecture: `boundary_spanning`
- `pi_out = 0.55`
- `pi_BS = 0.65`
- `k = 12`
- `b_grid = [1, 2, 4, 6]`
- `NG = 50`
- `NT = 50`
- `T_max = 50000`
- `n_boot = 10000`

## Main diagnostic

The script checks whether, as `b` increases and the approximate per-spanner load decreases, the following metrics decrease monotonically:

- RMST
- T95

The relevant condition sequence is:

```text
BS_b_01 → BS_b_02 → BS_b_04 → BS_b_06
```

The corresponding approximate load per boundary spanner is:

```text
6.0 → 3.0 → 1.5 → 1.0
```

## Contrast convention

Contrasts are computed as condition X minus condition Y.

For time metrics:

```text
positive value = condition Y is faster/lower
negative value = condition X is faster/lower
```

This is consistent with previous rerun_v2 exports.

## Interpretation guardrails

- These results refer to time to relational coordination readiness, not R&D performance.
- Increasing `b` changes the distribution of workload across boundary spanners while the cross-boundary tie budget remains fixed.
- RMST uses observed time `T_tilde`.
- Event quantiles are reported only when estimable.
- Censored trajectories are not converted into artificial event times.
- Bootstrap intervals are hierarchical and paired over matched graph and trajectory identifiers.
